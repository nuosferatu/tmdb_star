# 🎬 TMDB 影视库管理

一个简洁优雅的个人影视库收藏管理网页，使用 TMDB API 实现电影和电视剧的搜索、浏览和收藏功能。

## ✨ 功能特性

### 1. 搜索功能
- 🔍 在顶部搜索框输入电影或剧集名称
- 📄 分页显示搜索结果，每页10条
- 🖼️ 每个结果包含：海报缩略图、名称、发行时间、类型标签

### 2. 详情页面
- 🎨 大尺寸海报展示
- 📝 完整信息：名称、原始名称、发行时间、类型、评分、简介
- 📺 剧集信息：显示所有季和每季的所有集数（仅电视剧）
- ❤️ 收藏按钮：一键收藏/取消收藏

### 3. 收藏管理
- 🏠 首页展示所有收藏的影视作品
- 📌 新收藏的项目自动置顶
- 🎴 卡片式展示，包含更大的海报和标题
- 👆 点击卡片进入详情页

### 4. 管理模式
- ⚙️ 点击"管理收藏"按钮进入管理模式
- 🔄 拖拽卡片重新排序
- 🗑️ 每个卡片下方的删除按钮快速移除收藏

## 🚀 部署说明

### GitHub Pages 部署

1. 在 GitHub 仓库设置中启用 GitHub Pages
2. 选择部署分支（通常是 `main` 或 `gh-pages`）
3. 访问 `https://[你的用户名].github.io/tmdb_star/`

### 本地预览

```bash
# 使用 Python 启动本地服务器
python3 -m http.server 8080

# 或使用 Node.js
npx http-server -p 8080

# 然后在浏览器访问 http://localhost:8080
```

## 💾 数据存储

- 使用 `sessionStorage` 存储收藏数据
- 数据仅在当前会话有效
- 刷新页面或关闭浏览器后数据清空
- 无需后端服务器或数据库

## 🔑 API 配置

本项目使用 TMDB (The Movie Database) API：
- API Key 已内置在代码中
- 支持中文语言（`language=zh-CN`）
- 获取电影、电视剧的详细信息和海报图片

如需更换 API Key，请在 `index.html` 中修改 `API_KEY` 常量。

## 🎨 技术栈

- **纯前端实现**：单一 HTML 文件，包含 CSS 和 JavaScript
- **响应式设计**：支持桌面和移动设备
- **现代 UI**：渐变背景、卡片阴影、平滑过渡动画
- **拖拽功能**：HTML5 Drag and Drop API
- **异步 API 调用**：Fetch API + async/await
